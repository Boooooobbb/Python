### 一、基础入门
- 输入输出（`input`、`eval`、`print` 函数）
- 数据类型概述与变量命名

### 二、数据类型
- **Number**：整型、浮点型、复数型
- **String**：字符串操作、转义字符、子串截取
- **List**：列表的创建、索引与修改
- **Tuple**：元组的概念与操作
- **Set**：集合的创建与集合运算
- **Dictionary**：字典的创建与访问

### 三、运算符
- 占位运算符与算术运算符
- 赋值运算符、比较运算符、逻辑运算符
- 位运算符
- 身份运算符与成员运算符
- 序列运算符与运算符优先级

### 四、流程控制
- 条件语句（`if / elif / else`）
- 循环语句（`for` 循环、`while` 循环、`range` 函数）
- `break`、`continue` 与 `else`

### 五、函数
- 形参与实参
- 默认参数、不定长参数
- 拆分参数列表
- 返回值

### 六、模块
- 使用 `import` 导入模块
- 使用 `from ... import` 导入
- 全局变量 `__name__`
- 包与第三方模块的安装

### 七、变量作用域
- 局部变量与全局变量
- `global` 关键字
- `nonlocal` 关键字

### 八、面向对象编程（类）
- 类的定义与类属性
- 常用内置方法（`__init__`、`__del__` 等）
- 继承与方法重写
- 鸭子类型与 `super` 方法
- 私有属性、类方法、静态方法

### 九、数据结构进阶
- 列表：创建、拼接、查找、插入、删除、排序
- 元组的操作
- 集合的创建、插入与集合运算
- 字典：创建、修改、删除、拷贝及常用操作
- 切片与列表生成表达式
- 生成器与迭代器

### 十、字符串进阶
- 字符串的创建与比较
- 字符串切割
- 检索与替换
- 去除空格与大小写转换
- 占位符与 `format` 方法

### 十一、正则表达式
- 正则表达式基础语法
- `re` 模块：`compile`、`match`、`search`、`findall`、`finditer`
- `split`、`sub`、`subn`

### 十二、IO编程与异常处理
- `os` 模块的使用
- 异常处理（`try / except / finally`）
